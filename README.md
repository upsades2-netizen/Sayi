# سَعي

تطبيق ويب شخصي بسيط للدراسة باللغة العربية. البيانات محفوظة محليًا في المتصفح.

## الميزات

- مواد، فصول، ودروس/محاضرات.
- إكمال الدروس وحساب التقدم تلقائيًا لكل فصل ومادة.
- مهام اليوم ودروس اليوم.
- واجهة متجاوبة للهاتف والكمبيوتر.

## التشغيل

افتح `index.html` في متصفح حديث.

## البنية

- `index.html`: الواجهة.
- `assets/css/styles.css`: التصميم المتجاوب.
- `assets/js/app.js`: التفاعل والعرض.
- `assets/js/store.js`: التخزين المحلي القابل للاستبدال لاحقًا.
